# START HERE - Быстрый старт

Добро пожаловать в проект nBot! Этот файл поможет вам быстро начать работу.

## Что это за проект?

Telegram-бот для автоматизированного сбора данных (фото + диалог + описание сцены) с отправкой в n8n webhook для дальнейшей обработки.

## Быстрый старт (5 минут)

### Шаг 1: Получите токен бота

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте токен (формат: `1234567890:ABCdefGHI...`)

### Шаг 2: Настройте окружение

```bash
# Откройте файл .env
nano .env

# Замените your_telegram_bot_token_here на ваш токен
TELEGRAM_TOKEN=1234567890:ABCdefGHI...
N8N_WEBHOOK_URL=https://n8n.true-scale.ru/webhook/***REMOVED***
```

### Шаг 3: Установите зависимости

```bash
# Активируйте виртуальное окружение
source .venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### Шаг 4: Запустите бота

```bash
python bot.py
```

Вы должны увидеть:
```
INFO - Запуск бота...
INFO - Бот успешно запущен и готов к работе
```

### Шаг 5: Протестируйте

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Следуйте инструкциям бота

## Важные команды

### Разработка

```bash
# Запуск бота
python bot.py

# Форматирование кода
black bot.py

# Проверка стиля
flake8 bot.py

# Тесты
pytest tests/
```

### Продакшн (Docker)

```bash
# Сборка и запуск
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```

### Продакшн (systemd)

```bash
# Запуск
sudo systemctl start telegram-bot

# Логи
sudo journalctl -u telegram-bot -f

# Остановка
sudo systemctl stop telegram-bot
```

## Возможные проблемы

### Бот не запускается

- Проверьте, что токен в `.env` корректен
- Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
- Проверьте логи на наличие ошибок

### Бот не отвечает

- Проверьте, что бот запущен (смотрите логи)
- Убедитесь, что вы не заблокировали бота в Telegram
- Проверьте интернет-соединение

### Ошибка при отправке в webhook

- Проверьте доступность n8n webhook
- Убедитесь, что URL корректен в `.env`
- Проверьте логи n8n
