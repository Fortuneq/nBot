# Quick Start Guide

Быстрое руководство по запуску Telegram-бота.

## Шаг 1: Создание Telegram-бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "My Data Collection Bot")
4. Введите username для бота (должен заканчиваться на 'bot', например: "my_data_bot")
5. Скопируйте полученный токен (выглядит примерно так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Установка зависимостей

```bash
cd /Users/volkovvladislav/PycharmProjects/nBot
source .venv/bin/activate  # Активация виртуального окружения
pip install -r requirements.txt
```

## Шаг 3: Настройка конфигурации

Откройте файл `.env` и замените `your_telegram_bot_token_here` на токен, полученный от BotFather:

```env
TELEGRAM_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
N8N_WEBHOOK_URL=https://n8n.true-scale.ru/webhook/***REMOVED***
```

## Шаг 4: Запуск бота

```bash
python bot.py
```

Вы должны увидеть:

```
2025-12-08 21:15:30 - __main__ - INFO - Запуск бота...
2025-12-08 21:15:31 - __main__ - INFO - Бот успешно запущен и готов к работе
```

## Шаг 5: Тестирование бота

1. Откройте Telegram
2. Найдите вашего бота по username (например: @my_data_bot)
3. Отправьте команду `/start`
4. Нажмите кнопку "Начать генерацию" или отправьте `/generate`
5. Следуйте инструкциям бота:
   - Отправьте фото
   - Отправьте текст диалога
   - Отправьте описание сцены
6. Получите подтверждение об отправке данных

## Остановка бота

Нажмите `Ctrl+C` в терминале для остановки бота.

## Проверка отправки данных в n8n

После завершения процесса проверьте, что данные поступили в ваш n8n workflow:

1. Откройте n8n: https://n8n.true-scale.ru
2. Найдите workflow с webhook
3. Проверьте executions (выполнения)
4. Убедитесь, что payload содержит все необходимые поля

## Troubleshooting

### Ошибка: "TELEGRAM_TOKEN не установлен"

Убедитесь, что:
- Файл `.env` создан в корне проекта
- В файле `.env` указан корректный токен
- Токен не содержит лишних пробелов или кавычек

### Ошибка: "ModuleNotFoundError: No module named 'telegram'"

Установите зависимости:

```bash
pip install -r requirements.txt
```

### Бот не отвечает на сообщения

1. Проверьте, что бот запущен (в терминале нет ошибок)
2. Убедитесь, что вы не заблокировали бота в Telegram
3. Проверьте правильность токена в `.env`

## Полезные команды

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python bot.py

# Запуск в фоновом режиме (Linux/macOS)
nohup python bot.py > bot.log 2>&1 &

# Просмотр логов в реальном времени
tail -f bot.log

# Остановка фонового процесса
pkill -f bot.py
```
